# THE MODERN SOFTWARE ENGINEER — ZERO TO SELF-RELIANT (V2)
## 6-Month Live Curriculum (Beginner-Safe, Industry-Aligned, 2026+)

This V2 keeps the original strengths (project-based, end-to-end, deploy-first) and adds:
- Stabilization weeks
- Weekly debugging labs
- React + TypeScript
- Applied logic track
- Testing basics
- Modern deployment awareness (Vercel/Railway/Render + EC2 depth)
- AI from Week 1 (not only at end)
- Mobile-first quality gates
- No-AI build week
- Software team workflow exposure

---

## 1) Course Overview

- **Duration**: 24 weeks (6 months)
- **Delivery**: Live classes, 4 days/week, 2 hours/day
- **Audience**: Absolute beginners (zero IT background)
- **Core outcomes**:
  - Entry-level job readiness (frontend/full-stack junior profile)
  - Freelance readiness (client website/app delivery + deployment)
  - Founder readiness (MVP thinking + launch workflow)

### Primary Build Spine
Students build and continuously improve one real product:
- **BookEase**: Local business booking platform

Then they build a second capstone:
- **HireLocal**: AI-assisted local talent marketplace

## 4) Weekly Cross-Cutting Tracks (New in V2)

### A) Weekly Debugging Lab (45–60 mins/week)
Progressive bug banks:
- CSS layout collapse
- React re-render loops
- Type mismatch bugs in TS
- CORS failures
- 500 errors and bad request validation
- DB connection failures
- migration mismatch
- env variable missing in deployment

Debug workflow taught:
- stack trace reading
- browser console + network tab
- server logs
- print/log debugging
- AI-assisted debugging prompts

### B) Applied Programming Logic Track (2 micro-sessions/week)
Inside project context (not abstract DSA):
- arrays, filtering, sorting, searching
- object transforms
- pricing calculations
- booking conflict logic
- analytics aggregations

### C) Mobile-First Quality Gate
Every submission must pass:
- 320px, 375px, 768px checks
- navigation usable on touch
- forms readable and tappable

### D) AI Usage Policy
- AI allowed daily
- **No-AI build week mandatory** (Week 9)
- “Explain/edit/defend the code” rule for all AI-generated code

### E) Creative Motivation Blocks
- Best landing page redesign
- Best chatbot personality
- AI-to-manual refactor challenge
