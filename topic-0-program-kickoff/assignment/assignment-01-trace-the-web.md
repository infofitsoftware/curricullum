# Assignment — Trace the Web: From Click to Screen

**Topic 0 — Program Kickoff & Setup (all lessons)**  
**Type:** Individual written assignment (real-life IT literacy)  
**Due:** End of Week 1  
**Submit:** PDF or Word (1–2 pages) + optional simple diagram (photo/draw.io/hand-drawn OK)

---

## Business scenario

You are the **junior IT support trainee** at a small coaching institute. The director wants to launch an online class booking page (similar idea to **BookEase**). They ask you:

> “When a student types our website name in Chrome, what actually happens? And what’s the difference between that and when our developer tests on `localhost`?”

Your job is to write a **clear briefing document** a non-technical director can understand.

---

## Tasks

### Task 1 — Trace a real website journey (40%)

Pick **one** website or web app you use (e.g. `swiggy.com`, `youtube.com`, college portal).

Write **8 numbered steps** from the moment a user types the URL until content appears on screen.  
Each step must use at least **3** of these terms correctly:

- Browser  
- Server  
- Domain  
- DNS  
- IP address (mention once)  
- HTTPS (optional bonus)  
- Frontend (what user sees)

**Example step (do not copy):**  
“4. The browser sends an HTTPS request to the server at that IP address.”

---

### Task 2 — Developer machine vs live site (30%)

Compare **production** (live website) vs **development** (developer laptop) in a table with **at least 5 rows**:

| Aspect | Live website (production) | Developer laptop |
|--------|---------------------------|------------------|
| URL example | ? | ? |
| Who can access | ? | ? |
| DNS needed? | ? | ? |
| Typical port | ? | ? |
| ... | | |

Include rows for: **URL**, **audience**, **localhost**, **port** (give examples like 443 and 3000).

---

### Task 3 — Project folder & professional habits (20%)

1. Describe the **folder structure** you created in Hands-on Exercise 01 (list folders and 2 files).  
2. Write **3 terminal commands** you used and what each does in one line.  
3. State **one** bootcamp rule from Lesson 09 about AI use and why it matters for jobs.

### Task 4 — Mini glossary (10%)

Define in **your own words** (2–3 sentences each, no copy-paste from notes):

1. Coding vs programming (can say they’re similar for beginners — explain both)  
2. Vibe coding  
3. Prompt engineering (mention CCTO briefly)

## Real-life why this matters

- **IT support & QA roles** explain outages: “DNS issue” vs “server down.”  
- **Developer interviews** ask: “What happens when you type a URL?”  
- **Freelance clients** ask why they see `localhost` in your demo but a `.com` when live.

This assignment builds **communication skill** — not just memorization.
