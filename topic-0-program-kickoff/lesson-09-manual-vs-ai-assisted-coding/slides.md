# Lesson 09 — Manual vs AI-Assisted Coding

**Topic 0 | Week 1**

---

## Slide 1 — Title

# Manual vs AI-Assisted Coding
### Bootcamp rules for interview-proof learning

*AI is your accelerator — not your substitute.*

---

## Slide 2 — Why rules?

# Without rules

- Fail **no-AI** skill checks  
- Freeze in **interviews**  
- Can't debug on the **job**  

*We train human + AI — not human hides behind AI.*

---

## Slide 3 — Two modes

# Two ways to work

| Manual | AI-assisted |
|--------|-------------|
| **You** type core logic | AI drafts; **you** verify |
| New concepts & tests | Polish, boilerplate, debug help |

**Both are professional — pick the right mode.**

---

## Slide 4 — Rule 1–4

# Bootcamp rules (1–4)

1. **Manual first** on new topics  
2. **AI suggests — you decide**  
3. **Always run & test**  
4. **No AI** on marked skill checks  

---

## Slide 5 — Rule 5–8

# Bootcamp rules (5–8)

5. **Your** commit messages  
6. **No secrets** in prompts  
7. **Own** your portfolio  
8. **Stuck protocol** before blind AI loops  

---

## Slide 6 — Stuck protocol

# When stuck

1. Read error  
2. Notes / docs (15 min)  
3. Search error  
4. AI with **CCTO** + snippet  
5. Ask human help  

---

## Slide 7 — Manual means

# Manual ≠ no Google

**Manual =** you write core logic & can explain it.

**AI-assisted =** improves **your** draft.

*Week 2 HTML check: structure by hand.*

---

## Slide 8 — Good AI uses

# ✅ AI-assisted OK

- Boilerplate & layout drafts  
- Debug with error pasted  
- README after you understand project  
- Refactor with review  

---

## Slide 9 — Bad AI uses

# ❌ Stop

- Whole project, zero reading  
- No-AI assessment cheating  
- Code you can't explain  
- Secrets in chat  

---
