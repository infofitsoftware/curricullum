## Slides → PowerPoint

Each `slides.md` file uses `---` between slides (Marp / slide-deck format). To build a PPT:

1. Open `slides.md` in VS Code/Cursor with the **Marp** extension, export to `.pptx`, **or**
2. Copy each slide block into PowerPoint (one slide per section).
