## Slide 2 — Why learn this?

# Real developers use

- Organized **files & folders**  
- **Terminal** commands  
- **Localhost** for testing  
- **Ports** to run multiple services  

*Not just double-clicking icons.*

---

## Slide 3 — Files

# Files

Named containers for data.

| File | Type |
|------|------|
| `index.html` | Web page |
| `app.py` | Python |
| `style.css` | Styles |

**Rule:** Clear names — `login-form.html` not `a.html`

---

## Slide 4 — Folders

# Folders (directories)

Group related files.

```
bookease/
├── index.html
├── css/
├── js/
└── images/
```

**Analogy:** Almirah drawers — tidy project = fewer bugs.

---

## Slide 5 — Paths

# Finding files

- **Relative:** `css/style.css`  
- **Absolute:** `C:\Users\You\Projects\bookease\...`

*IDE shows the tree — terminal uses paths.*

---

## Slide 6 — Terminal

# Terminal = command line

Type **commands** → computer executes.

**Uses:** start servers, Git, install packages, cloud servers.

**Open in Cursor:** `` Ctrl + ` `` (backtick)

**Analogy:** Short voice orders to a fast assistant.

---

## Slide 7 — Commands cheat sheet

# Starter commands

| Action | Command |
|--------|---------|
| List files | `dir` / `ls` |
| Change folder | `cd foldername` |
| Go up | `cd ..` |
| New folder | `mkdir name` |
| Where am I? | `pwd` |

*Practice in a `practice` folder.*

---

## Slide 8 — Localhost

# Localhost = this computer

- `http://localhost`  
- IP `127.0.0.1`  

**Dress rehearsal** before public launch.

| Dev | Live |
|-----|------|
| localhost:3000 | yoursite.com |

*Only YOU see localhost.*

---

## Slide 9 — Ports

# Ports = numbered doors

`http://localhost:3000` → port **3000**

| Port | Service |
|------|---------|
| 443 | HTTPS live site |
| 3000 | React dev |
| 8000 | Python API |
| 5432 | PostgreSQL |

*One laptop, many services, different ports.*

---

## Slide 10 — Dev vs production

# Same idea, different scale

| Production | Your laptop |
|------------|-------------|
| flipkart.com | localhost |
| DNS → IP | 127.0.0.1 |
| Data center | Your process |
| Port 443 | Port 3000 |
