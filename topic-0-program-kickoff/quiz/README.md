## Moodle import steps

1. Log in as teacher → your course.  
2. **Question bank** → **Import**.  
3. **File format:** Moodle XML.  
4. Upload `topic-0-quiz.xml`.  
5. **Import**.  
6. Create a **Quiz** activity → add questions from bank → set passing grade (suggest 70%, 25 questions × 1 point).  
7. Enable **Shuffle within questions** in quiz settings (redundant with XML shuffle but recommended).

## Other LMS

- **Canvas:** Convert via third-party tool or re-enter; Canvas QTI uses different XML.  
- **Google Forms:** Use questions as reference to build form manually.  
- **Manual:** Each question has general feedback for answer explanations.
