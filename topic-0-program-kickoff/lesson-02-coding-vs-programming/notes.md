# Lesson 02 — What Is Coding vs What Is Programming?

**Duration:** 45–60 minutes  
**Prerequisite:** None  
**Goal:** Students can explain coding, programming, and software in simple words with real examples.

---

## 1. Opening hook (5 min)

Ask the class:

- “Who used a phone app today?” (WhatsApp, Paytm, Instagram)
- “Who ordered food online?” (Zomato, Swiggy)
- “Who visited a website?” (Google, college portal, Netflix)

**Point:** Behind every app and website, someone wrote **instructions** for the computer. That work is **coding** and **programming**.

---

## 2. What is a programming language?

A **programming language** is a structured way to write instructions the computer can execute.

| Human language | Programming language |
|----------------|----------------------|
| Hindi, English | Python, JavaScript, Java |
| Talk to people | Talk to machines |
| Grammar rules | Syntax rules |

**Real-life analogy — recipe book:**  
“Add 2 cups rice” is like `print("Hello")` — one clear step in a known format.

**Technology example:**  
When you send “Hi” on WhatsApp, code written in languages like **Erlang**, **Java**, or **C++** (plus many others) routes your message in milliseconds.

**Languages you will use in this bootcamp:** HTML, CSS, JavaScript, TypeScript, Python, SQL.

---

## 3. What is coding?

**Coding** = the act of **writing** those step-by-step instructions in a programming language.

Think of a robot that follows orders **literally**:

| You say (idea) | You code (instruction) |
|----------------|------------------------|
| Greet the user | `print("Welcome to BookEase")` |
| If password wrong, show error | `if password != saved: show_error()` |
| Add item to cart | `cart.append(item)` |

**Real-life analogy — GPS directions:**  
“Turn left at the signal” must be exact. Missing a step = wrong result (robot goes the wrong way).

**Technology example — ATM:**  
1. Read card  
2. Ask for PIN  
3. Check balance in database  
4. Dispense cash or show error  

Each step is coded by developers.

---

## 4. What is programming?

**Programming** is the **bigger job** of using code to **solve a problem** and **build working software**.

It includes:

- Understanding the problem (What should the app do?)
- Planning (What screens? What data?)
- **Coding** (Writing the instructions)
- Testing (Does it work? What if user clicks twice?)
- Fixing bugs (Debugging)
- Improving over time

**Real-life analogy:**

| Activity | Software world |
|----------|----------------|
| Cooking one dish | Coding one feature |
| Running a restaurant | Programming the whole product |

**Technology example — Zomato order flow:**  
Programming = designing login, restaurant list, cart, payment, delivery tracking, and notifications.  
Coding = writing the actual lines for “show restaurant rating” or “apply coupon code.”

---

## 5. Coding vs programming — the simple answer for beginners

| Term | Beginner-friendly meaning |
|------|---------------------------|
| **Coding** | Writing the instructions (the “how”) |
| **Programming** | Solving the problem with software (the “what” + “how” + “does it work?”) |

**In interviews and daily talk:** Most people use both words the same way.

- “I **code** in Python” ✅  
- “I **program** in Python” ✅  
- “I’m learning to **code**” ✅  

**When there is a difference (good to know):**

- **Coder** (casual) → writes code, often for one task or script  
- **Programmer / Developer** → plans features, writes code, tests, fixes, ships products  

You are training to become a **developer** — you will **code** every day as part of **programming** real apps.

---

## 6. What is software / an application?

**Software** (or **app**) = the finished product users run or visit.

| Type | Example | Device |
|------|---------|--------|
| Mobile app | PhonePe, Instagram | Phone |
| Website | Wikipedia, company brochure site | Browser |
| Web app | Gmail, Google Docs | Browser (feels like software) |
| Desktop app | MS Excel, VLC | Laptop/PC |

**Chain to remember:**

```
Problem → Programming (plan + build) → Coding (write instructions) → Software (users use it)
```

---

## 7. Mini activity — “Human robot” (10 min)

**Exercise (no computer):**  
One student is the **robot**. Teacher gives English instructions; robot only follows **exact** words.

Try: “Make a paper airplane.”  
Then try ultra-precise steps: “Pick up paper. Fold in half lengthwise. …”

**Debrief:** Computers are like the robot. **Coding** is being precise. **Programming** is knowing the goal (airplane) and breaking it into steps.

---

## 8. Key takeaways

1. **Programming language** = vocabulary and grammar for computers.  
2. **Coding** = writing step-by-step instructions in that language.  
3. **Programming** = full process of building software that solves a real problem.  
4. For beginners, “coding” and “programming” often mean the same thing — both are fine.  
5. Your job path: learn to **code** so you can **program** apps like **BookEase**.

---

## 9. Common beginner questions

**Q: Do I need to be good at math?**  
A: Basic logic helps; you don’t need advanced math for web development.

**Q: Which language should I learn first?**  
A: This course starts with **HTML/CSS** (web structure and style), then **JavaScript**, then **Python** for backend.

**Q: Is HTML a programming language?**  
A: HTML describes page **structure**. We call it markup; it’s essential for web dev even though it’s not used for heavy logic like Python.

---

## 10. One-minute recap script (for instructor)

> “Coding is writing instructions. Programming is using those instructions to build real software. You’ll code in many languages and program full products — starting with a booking platform called BookEase. Today you don’t need to memorize syntax; you need to understand the words.”
