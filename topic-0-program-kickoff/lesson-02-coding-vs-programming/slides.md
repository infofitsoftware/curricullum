## Slide 3 — Programming language

# What is a programming language?

A **structured way** to give instructions to a computer.

| People | Computers |
|--------|-----------|
| Hindi, English | Python, JavaScript |

**Analogy:** Recipe language — “2 cups flour” = one clear step.

---

## Slide 4 — Bootcamp languages

# Languages in *this* course

- **HTML / CSS** — web pages  
- **JavaScript / TypeScript** — interactivity & React  
- **Python** — backend & APIs  
- **SQL** — database  

*Different tools for different jobs — like carpenter vs electrician.*

---

## Slide 5 — What is coding?

# Coding = writing instructions

**Step-by-step commands** in a programming language.

```
print("Welcome to BookEase")
```

**Analogy:** GPS for a robot — miss one turn, wrong destination.

---

## Slide 6 — Coding example (ATM)

# Real technology: ATM

1. Read card  
2. Ask PIN  
3. Check balance  
4. Give cash **or** show error  

Each step = **coded** by developers.

---

## Slide 7 — What is programming?

# Programming = building the solution

Includes:

- Understand the problem  
- Plan the app  
- **Write code**  
- Test & fix bugs  
- Ship to users  

**Analogy:** Coding = one dish. Programming = running the kitchen.

---

## Slide 8 — Zomato example

# Programming a food app

| Feature | Needs code? |
|---------|-------------|
| Login | ✅ |
| Restaurant list | ✅ |
| Cart & payment | ✅ |
| Delivery tracking | ✅ |

**Programming** = the whole journey. **Coding** = each feature’s instructions.

---

## Slide 9 — Side by side

# Coding vs Programming

| Coding | Programming |
|--------|-------------|
| Write instructions | Solve problem with software |
| The “how” (lines of code) | The “what + how + does it work?” |
| One feature / script | Full product |

*Beginners: often used as the same word — that’s OK.*
