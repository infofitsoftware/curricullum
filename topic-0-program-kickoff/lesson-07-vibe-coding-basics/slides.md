# Vibe Coding Basics

---

## Slide 2 — What is vibe coding?

# Vibe coding

Describe what you want in **plain language** → AI writes/edits code → **you** guide & verify.

**Analogy:** Architect (you) + fast contractor (AI).  
**You** inspect before handover.

---

## Slide 3 — Your tools

# Tools in this bootcamp

| Tool | Use |
|------|-----|
| **Cursor** | Main IDE + AI in project |
| **ChatGPT / Claude** | Explain, debug, plan |

*Code lives in folders — not just chat.*

---

## Slide 4 — Good for

# ✅ AI helps with

- Starting boilerplate (HTML skeleton)  
- Repetitive code  
- Explaining errors  
- Refactors & README drafts  

*80% from AI + 20% your fixes = real workflow.*

---

## Slide 5 — Bad for

# ❌ AI hurts when

- Blind copy-paste  
- Skipping learning  
- Pasting **passwords / API keys**  
- Trusting without **running** code  
- No-AI skill checks 🚫  

---

## Slide 6 — The loop

# Responsible vibe coding loop

```
DEFINE → PROMPT → GENERATE → READ → RUN → FIX → COMMIT
```

**Taste the food before serving guests.**

---

## Slide 7 — When to use AI

# AI vs your brain

| Situation | Approach |
|-----------|----------|
| New topic | Try first, then AI |
| Weird error | Paste error + code |
| Interview demo | Must understand all |

**Manual first. AI second.**

---

## Slide 8 — Ethics

# Honesty matters

- Portfolio = code **you** can explain  
- Interviews: “How does login work?” — **you** answer  
- AI assist ≠ zero learning
