# Part 3 — Module Assignment

## Title
**Software Foundations Briefing Pack for a Real Product Idea**

## Scenario
You are a junior trainee asked to prepare a briefing for a founder who wants to build a software product. The founder is non-technical. Your job is to show Module 1 mastery and prepare the idea for Module 2+.

## Deliverables (single PDF/Markdown, 800–1200 words)

### Section A — Product snapshot
* Working product name  
* Problem in 2–3 sentences  
* Target users  
* Success definition for MVP (2 bullets)

### Section B — Software classification
* Primary software form (website / web app / mobile app / SaaS-style web product)  
* Justification (user behavior + constraints)  
* One alternative form and why it is secondary for now  

### Section C — SDLC plan (4 weeks)
Create a week-by-week plan using SDLC thinking + Agile increments:

| Week | Focus stage(s) | Deliverable increment |
|------|----------------|-----------------------|
| 1 | | |
| 2 | | |
| 3 | | |
| 4 | | |

Include at least one testing activity and one feedback activity.

### Section D — Team design
Propose a 4-person team:

* roles;
* who owns what;
* one collaboration ritual (standup/review/retro).

### Section E — Career reflection
In 8–10 lines:

* which role you want to grow toward first;
* which Module 1 concepts help that path;
* how you will use AI responsibly while learning fundamentals.

## Constraints
* No code required.  
* No fake claims of advanced expertise.  
* India-relevant example preferred but not mandatory.  
* If AI helps outline, disclose in one footnote and write final text yourself.

## Rubric (100 points)

| Criteria | Points |
|----------|--------|
| Clear problem/users/MVP success | 15 |
| Sound software-form decision | 20 |
| SDLC/Agile weekly plan quality | 25 |
| Team roles & collaboration realism | 15 |
| Career reflection honesty & clarity | 15 |
| Professional writing/structure | 10 |
