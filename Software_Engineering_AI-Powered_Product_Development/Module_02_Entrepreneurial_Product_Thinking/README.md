# Module 2 — Entrepreneurial & Product Thinking

**Outcome:** Students identify a real-world problem and select a potential software product they can develop throughout the course.

**Teaching style:** Interactive discussion-led lessons (teacher prompts + student activities) grounded in campus/home/local life.

**Assessment style:** One consolidated module assessment (no per-chapter exercises).

## Suggested classroom flow

1. Ch 1 — Problem Hunt board + exit ticket (3 candidate pains)  
2. Ch 2 — Product autopsy + weak-idea upgrade + peer critique  
3. Ch 3 — Brainstorm → score → decision statement approvals  
4. Assessment — practice → quiz → **Course Product Decision Pack**
