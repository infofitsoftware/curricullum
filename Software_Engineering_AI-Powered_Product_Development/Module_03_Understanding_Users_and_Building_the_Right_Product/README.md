# Module 3 — Understanding Users & Building the Right Product

**Outcome:** Students convert their project idea into a defined problem, target user, user stories, feature list, and MVP.

**Philosophy:** Short concept teaching · frequent teacher–student discussion · grounded in each student’s Module 2 product · one consolidated assessment.

## Chapters

| Chapter | Focus | File |
|---------|--------|------|
| 01 | Users, interviews, personas | `Chapter_01_Understanding_Your_Users_Learning.md` |
| 02 | Problem statement, user stories | `Chapter_02_Defining_the_Problem_Learning.md` |
| 03 | Must-have vs nice-to-have | `Chapter_03_Defining_Product_Features_Learning.md` |
| 04 | MVP | `Chapter_04_Building_an_MVP_Learning.md` |

## Assessment (single file)

`Module_03_Assessment_Exercises_Quiz_Assignment.md`

* Exercises (incl. discussion rounds)  
* Quiz (15 Q)  
* Outcome Assignment: **Product Definition Pack**

## Classroom rhythm (suggested)

Each chapter: **short teach → activity → discussion → exit ticket**  
Do not lecture the full document. Use it as facilitator guide + student reference.

## Continuity

Accepted Module 3 pack becomes the source of truth for Module 5+ design/build work.
