# Part 3 — Outcome Assignment

## Title
**Product Definition Pack (User → Problem → Stories → Features → MVP)**

## Goal
Prove Module 3 outcome using your approved Module 2 product.

## Deliverable (1 document, 800–1100 words max)

### 1) Target user
* Primary user  
* Secondary user (if any)  
* 3 bullet insights from interview(s) or direct conversation notes  
* Simple persona (half page max)

### 2) Problem statement
Final polished statement + current workaround + failure point.

### 3) User stories (6 minimum)
At least 4 for primary user, 2 for secondary/admin if relevant.  
Mark top 3 as MVP stories.

### 4) Feature list
Three columns:

* Must-have (max 5)  
* Nice-to-have  
* Not now  

Each must-have mapped to at least one story.

### 5) MVP definition
One-pager:

* core job  
* what is included  
* what is excluded  
* how a real user will try it  
* what you will learn  

### 6) Commitment line
> For **[user]**, my MVP helps them **[core job]** by **[must-have capabilities]**. I am delaying **[key not-now items]** on purpose.

## Rules
* Stay grounded in your real product idea.  
* No fake research claims. If you could not interview yet, label assumptions clearly and show planned interviews.  
* AI may help formatting only; disclose if used.  
* Teacher must accept this pack before UI/branding modules treat it as source of truth.

## Rubric (100)

| Criteria | Points |
|----------|--------|
| Specific target user + evidence/assumptions honesty | 20 |
| Clear problem statement | 15 |
| Quality user stories | 20 |
| Sensible must-have / nice-to-have / not-now split | 20 |
| Viable MVP definition + learning goal | 20 |
| Clarity and focus | 5 |

**Pass:** 70+
