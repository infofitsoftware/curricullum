# Module 4 — AI for Software Engineers

**Outcome:** Students use AI as a development assistant rather than blindly copying AI-generated code.

**Positioning:** This is an **AI-powered full-stack developer** module — not a standalone prompt-engineering diploma. Depth is high where engineers must be literate (models, tokens, context, tools, cost, responsibility).

**Teaching style:** Concept blocks + frequent discussion + live tool demos by teacher + single consolidated assessment.
